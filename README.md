## The entry

> This paperclip held my thesis together for four years, then unbent itself into a SIM-ejector tool the day I actually needed a paperclip.

The joke is the object's own behaviour: a paperclip's entire career
is quiet loyalty — four years holding a thesis — until the one moment
you need it to be a paperclip, when it has already been unbended into
a SIM-ejector tool, a lockpick, or a phone-reset pin. Everyone has
done this to a paperclip. Nobody has ever done it on purpose and been
happy about it. The dullness is the punchline: the most boring object
in the drawer quits its job the day you finally notice it.

## Running

```sh
python3 main.py   # writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```

`main.py` is pure Python 3 stdlib: it reads the committed `entry.txt`,
writes it to the output directory, and prints it. No network, no
randomness, fully deterministic.
